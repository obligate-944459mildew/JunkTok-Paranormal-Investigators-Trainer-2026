## 🔥 Project Overview

**This tool** is a comprehensive trainer for **JunkTok: Paranormal Investigators Challenge**. This trainer assists with the game's five-night investigation challenge by improving survival, run progression, scan assignments, viewer rankings, and build management. It is intended for offline or private single-player use and should not be used in public online sessions.

**Target Audience:** Players who want to experiment with different builds, practice investigation routes, complete five-night runs more easily, or explore the game's paranormal systems without normal progression limits.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Explore each investigation area in first-person view and stay aware of creature activity, environmental effects, surveillance systems, and other run modifiers. Use the trainer's survival assistance when learning routes or testing movement through dangerous areas.

### Tools & Inventory

Carry the equipment needed to collect EyeAI data and investigate creatures, slime, and portals. Build-focused trainer options are best used to test perk and upgrade combinations without repeatedly restarting a run.

### World & Environment

Each run spans five nights from Monday through Friday. Complete EyeAI assignments, respond to donation requests, monitor viewer reactions, and adapt to effects such as air quality, allergies, tarot cards, zodiac signs, masks, filters, pranks, bets, components, and surveillance cameras.

### Combat & Weapons

JunkTok focuses on paranormal investigation and PvE survival rather than conventional weapon-based combat. Avoid or endure creature encounters while collecting evidence. The trainer's protection options are intended for safe exploration and learning creature behavior.
